# World Engine 世界引擎

**让 AI 角色在一个世界里自由生长，而你，是那个创世神。**

一个基于 **多 Agent + LangGraph** 的叙事模拟引擎。每个角色拥有独立的
人格、记忆与目标，在同一世界观下自由互动——交谈、猜疑、结盟、背叛。
你作为额外的变量随时介入：投下一枚石子，看涟漪如何搅动整个江湖。

</div>

---

## 为什么会有这个项目

用 AI 写小说已经不稀奇了，但单模型写出来的故事往往**经不起推敲**：角色前后矛盾、动机单薄、情节苍白。

World Engine 换了一条路：**不写故事，造世界**。让角色在明确的世界观和规则下自主行动，让复杂情节从角色之间的互动中**涌现**出来。人为构造剧情的瑕疵，被交给了角色们自己的"生活"去修正。

而你不是旁观者——你是**创世神**，通过一条独立的导演通道向世界注入变化。

---

## ✨ 核心特性

| 特性 | 说明 |
|---|---|
| 🎭 **多角色自由互动** | 每个角色有独立人格（核心层/表层/记忆层）、目标、秘密，自主说话与行动 |
| 🧠 **三因子记忆检索** | 基于 `recency × importance × relevance`（斯坦福 Generative Agents 设计）——角色只"记得"对自己重要的事 |
| 🌍 **世界状态持久化** | 全部事件、记忆、叙述沉淀到 SQLite，世界可跨会话续写 |
| 🎬 **创世神导演通道** | 随时注入事件，可定向到特定角色——"一只血染的信鸽落在沈雁的桌上" |
| 🔀 **多供应商可插拔** | 一个配置文件切换 DeepSeek / OpenAI / Ollama / Gemini / OpenRouter |
| 📜 **叙述者渲染** | 角色的内心戏、对白、动作被叙述者编织成小说文本 |

## 🏗 架构

```
┌─────────────────────────────────────────────────────────────┐
│                          CLI 控制台                          │
└──────────────────────────────┬──────────────────────────────┘
                               │ 回车推进 / event 注入
┌──────────────────────────────▼──────────────────────────────┐
│                     LangGraph 回合管线                        │
│                                                              │
│   apply_director ──► perceive ──► act ──► narrate ──► persist │
│   (导演事件落地)      (角色感知)     (角色行动)  (叙述成文)  (写库)│
└──────────────────────────────────────────────────────────────┘
        │ 检索记忆                          │ 读写
┌───────▼────────┐                   ┌──────▼──────┐
│ 三因子记忆检索   │                   │  SQLite     │
│ 角色人格模型     │                   │ 世界/事件/记忆 │
└────────────────┘                   └─────────────┘
        │                                │
┌───────▼────────────────────────────────▼──────┐
│            LLM 适配层（OpenAI 兼容协议）          │
│  DeepSeek · OpenAI · Ollama · Gemini · OpenRouter│
└──────────────────────────────────────────────────┘
```

**回合循环**：每个角色先感知当前场景，从自己的记忆流中检索相关内容，再独立决定"想什么、说什么、做什么"，最后叙述者把这一切织成一段小说文字。

## 🚀 快速开始

```bash
# 1. 克隆并安装
git clone https://github.com/MysEon/WorldEngine.git
cd WorldEngine
uv sync

# 2. 配置 LLM（config.yaml 默认 DeepSeek）
$env:DEEPSEEK_API_KEY = "sk-你的key"

# 3. 进入世界
uv run world-engine
```

### CLI 命令

```
(直接回车)            推进一回合，看角色们自由发展
event <描述>          作为创世神注入一个事件
event <描述> @沈雁,@阿蛮   注入事件并指定直接感知的角色
status                查看世界状态
history               查看最近事件
quit / exit           退出
```

## 🗺 预设世界

### 《荒山茶馆》

> 边陲小镇外的荒山上，一间四面漏风、挂着褪色酒旗的茶馆。
> 江湖人在这里歇脚，风声比人声多……

| 角色 | 身份 | 心事 |
|---|---|---|
| **沈雁** | 归隐剑客 | 十年前灭门惨案的真凶，最近好像回来了…… |
| **阿蛮** | 初出茅庐的少年 | 师父临终托付的一封信，还没送到柳城 |
| **柳娘** | 茶馆老板娘 | 这条山路的"耳朵"，知道每个人的底细 |

## 🗺 路线图

- [x] v0.1 — 多角色对话循环 + 创世神注入 + 记忆检索 + 持久化
