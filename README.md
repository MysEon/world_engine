# World Engine 世界引擎

**让 AI 角色在一个世界里自由生长，再把他们的故事，写成一本前所未有的小说。**

一个基于 **多 Agent + LangGraph** 的**小说生成系统**。每个角色拥有独立的人格、记忆与目标，
在同一世界观下自由互动——交谈、猜疑、结盟、背叛。你作为创世神随时介入，投下一枚石子，
看涟漪如何搅动整个江湖。而这一切互动只是**素材**——系统最终会把这些事件流，
**蒸馏成一部有起承转合的小说**。

</div>

---

## 为什么会有这个项目

用 AI 写小说已经不稀奇了，但单模型写出来的故事往往**经不起推敲**：角色前后矛盾、动机单薄、情节苍白。

World Engine 换了一条路：**不写故事，造世界**。让角色在明确的世界观和规则下自主行动，
让复杂情节从角色之间的互动中**涌现**出来——这是**素材层**。

但互动不是终点。**小说层**才是核心：系统从结构化的事件流（谁说了什么、做了什么、内心怎么想）
出发，由大纲规划 → 章节成文 → 润色校验，产出一本真正的、有文学性的小说。
人为构造剧情的瑕疵，被交给了角色们自己的"生活"去修正；而叙事品质，由小说撰写管线负责。

## ✨ 核心特性

| 特性 | 说明 |
|---|---|
| 📖 **小说撰写管线**（核心） | 事件流 → 大纲规划 → 章节成文 → 润色校验 → 导出 Markdown 成品书 |
| 🎭 **多角色自由互动** | 每个角色有独立人格（核心层/表层/记忆层）、目标、秘密，自主说话与行动 |
| 🧠 **三因子记忆检索** | 基于 `recency × importance × relevance`（斯坦福 Generative Agents 设计）——角色只"记得"对自己重要的事 |
| 🪞 **记忆压缩与反思** | 写入去重 + 周期反思：角色定期复盘经历，沉淀高维洞察，低价值旧记忆自动归档，长跑不爆 |
| 🌍 **世界状态持久化** | 全部事件、记忆、叙述沉淀到 SQLite，世界可跨会话续写 |
| 🎬 **创世神导演通道** | 随时注入事件，可定向到特定角色——"一只血染的信鸽落在沈雁的桌上" |
| 🔀 **多供应商可插拔** | 一个配置文件切换 DeepSeek / OpenAI / Ollama / Gemini / OpenRouter |

## 🏗 架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                           CLI 控制台                                  │
└───────────────┬──────────────────────────────┬──────────────────────┘
                │ 回车推进 / event 注入          │ outline / write / export
┌───────────────▼──────────────┐      ┌────────▼─────────────────────┐
│   素材层：世界模拟               │      │  产品层：小说撰写（核心）         │
│                              │      │                              │
│  LangGraph 回合管线            │      │  planner    事件流 → 大纲       │
│  apply_director→perceive      │      │  writer     逐章成文            │
│  →act→narrate→persist→reflect │      │  editor     润色校验            │
│                              │      │  export     导出 Markdown 书    │
└───────────────┬──────────────┘      └────────▲─────────────────────┘
                │ 事件流(SQLite events)         │ 读取结构化事件流
                └──────────────────────────────┘
┌─────────────────────────────────────────────────────────────────────┐
│            LLM 适配层（OpenAI 兼容协议）                                │
│  DeepSeek · OpenAI · Ollama · Gemini · OpenRouter                     │
└─────────────────────────────────────────────────────────────────────┘
```

**回合循环**：每个角色先感知当前场景，从自己的记忆流中检索相关内容，再独立决定"想什么、说什么、做什么"，叙述者把这一切织成场景白描，并沉淀进事件流。

**小说管线**：小说层只读结构化事件流，与模拟层解耦——**模拟层管"发生了什么"，小说层管"怎么被讲述"**。事实与叙事分离，文笔品质完全由小说管线负责。

## 🚀 快速开始

```bash
# 1. 克隆并安装
git clone https://github.com/MysEon/WorldEngine.git
cd WorldEngine
uv sync

# 2. 配置 LLM（config.yaml 默认 DeepSeek）
$env:DEEPSEEK_API_KEY = "sk-你的key"

# 3. 进入世界
uv run world-engine
```

### CLI 命令

```
(直接回车)            推进一回合，看角色们自由发展
event <描述>          作为创世神注入一个事件
event <描述> @沈雁,@阿蛮   注入事件并指定直接感知的角色
status                查看世界状态
history               查看最近事件
outline               根据事件流生成小说大纲
write [all|N]         撰写章节（默认 all，可指定章节号）
export [路径]         导出小说为 Markdown 成品
quit / exit           退出
```

每个回合除了场景正文，还会显示 **创世神视图**——每个角色完整的内心独白、言语、行动与记忆沉淀，你作为创世神可以看穿一切：

```
【创世神视图】
· 沈雁
    内心: 此人来路不明，我须留神他袖口下的那截刀柄。
    说: "这位兄台，面生得很，打哪儿来？"
    行动: 端起茶碗，目光却暗暗扫向门口。
    记忆沉淀: 茶馆里来了个带刀的生面孔
```

这些独白与行为同时沉淀进事件流，成为小说撰写的素材——但**小说正文是独立的艺术创作**，是否、以及如何呈现角色的内心，由小说管线自行拿捏，不会强制暴露。

### 典型工作流

```
回车 x N → 让角色们自由互动、注入几个事件
outline  → 系统把事件流切分为章节大纲
write    → 逐章成文 + 润色
export   → 得到一本《荒山茶馆》的 Markdown 书
```

> 边陲小镇外的荒山上，一间四面漏风、挂着褪色酒旗的茶馆。

| **阿蛮** | 初出茅庐的少年 | 师父临终托付的一封信，还没送到柳城 |

## 🗺 路线图

- [x] v0.1 — 多角色对话循环 + 创世神注入 + 记忆检索 + 持久化
- [x] 记忆压缩与反思——写入去重、周期复盘、低价值记忆归档，长跑不爆

- [ ] 导演事件链——起承转合的事件脚本，而非离散注入

- [ ] 角色关系状态机——好感/信任随互动演化
